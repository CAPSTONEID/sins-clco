# 페이퍼 콜라주: 장면과 모션의 변주

반복되는 제목+동일 카드 배열을 스타일의 일관성으로 오해하지 않는다. 색·종이 재질·서체는 유지하되 내용의 관계가 배치와 동작을 결정한다. 이 문서는 모든 요소에 같은 스티커 진입을 강제하던 지침보다 우선한다.

## 내용에서 배치로

| 내용 | 화면 구조 | 의미가 있는 동작 |
|---|---|---|
| 메일·전달 | 봉투와 꺼낸 메모 | 봉투 열기, 메모 인출 |
| 전역·개별 규칙 | 큰 원본 위 작은 적용 문서 | 문서 펼치기, 적용 범위 선택 |
| 작성 절차 | 줄 있는 원고지·번호 목록 | 행 리빌, 선택 행 밑줄 |
| 자료 분류 | 종이 폴더와 문서 묶음 | 파일 삽입·추출·재정렬 |
| 순서 | 단계별 종이와 연결선 | 단계 안착 후 선 그리기 |
| 조건 | 공통 출발점에서 갈라진 도해 | 분기선, 해당 결과 선택 |
| 여러 원인 | 중심 개념과 주변 메모 | 관련 메모 연결 |
| 수정 전후 | 교정지와 대체 문구 | 취소선 후 새 문구 덧붙이기 |
| 핵심 질문·결론 | 대형 단어와 작은 근거 메모 | 종이 펼침 후 단어 마스크 리빌 |

종이 도해는 정보를 설명해야 한다. 변주 숫자를 채우려고 장식·불필요한 문구를 추가하지 않는다. 긴 설명은 작은 글씨로 밀어 넣지 말고 문구를 줄이거나 종이 공간을 확장한다. 제목과 본문을 독립 영역에 두며 긴 제목이 필요한 장면은 좌측 제목+우측 도해 등으로 바꿀 수 있다. 영상에서는 웹PT 기본 배치를 모든 장면에 강제하지 않는다.

## 다른 프로파일에서 가져올 수 있는 것

[video-style-profiles.md](video-style-profiles.md)의 Finder 문법에서 선택→상세, 폴더→문서, 스택 재정렬을 참고한다. 창 테두리나 툴바를 그대로 이식하지 않고 종이 묶음과 문서 펼침으로 바꾼다. 네오 브루탈리즘에서는 카드·텍스트·강조의 타이밍을 분리하는 원리를 참고한다. 종이에서는 잉크 스탬프·행 마스크·밑줄을 쓰며 굵은 외곽선, 디지털 버튼 팝, 하드 섀도는 가져오지 않는다.

기존 문서에 있는 유튜브 링크를 직접 재생하지 못했다면 ‘문서화된 모션 규칙 참고’라고 기록한다. 링크 접근 실패를 실제 영상 분석으로 표현하지 않는다.

## 조립과 전환

- 본문 장면마다 표준 포인터가 최소 한 번 의미 있는 대상과 상호작용한다. 붙이기만 반복하지 않고 선택·펼치기·분류·교정을 내용에 맞춰 쓴다. 모든 조각을 화면 밖에서 가져올 필요는 없다.
- 종이 등장과 글자 강조를 분리한다. 이미 펼쳐진 문서에 행을 공개하거나, 커서 선택 후 밑줄을 그리거나, 폴더에서 문서를 꺼낸 뒤 핵심 단어를 보여 준다.
- 장면 시작 1초 안에 주제와 관련된 종이 구조·도해를 보여 준다. 제목만 남긴 채 다음 발화까지 빈 화면으로 기다리지 않는다. 실제 발화의 핵심 공개 시점은 유지한다.
- 전환은 가장자리 종이 덮기, 덮인 종이 밀기, 페이지 펼침, 콜라주 재배열을 내용에 맞춰 조합한다. 중앙 갈라짐·빈 배경 노출·끊임없는 흔들림은 금지한다.
- 읽는 구간에는 움직임을 줄인다. 큰 동작을 동시에 과도하게 겹치지 않는다.

## 반복 검수

스토리보드 또는 motion-ledger에 실제 배치, 주동작, 텍스트 강조, 전환, 내용상 이유를 기록한다. 이름만 다른 동일 좌표·동일 효과는 같은 배치로 센다.

- 동일 배치와 동일 주동작의 조합이 3장면 연속이면 수정한다.
- 본문 6장면 이상인 롱폼은 내용이 허용하는 범위에서 5종 이상 배치를 설계한다. 3장면 이상인 숏폼은 3종 이상을 목표로 한다. 짧은 영상에 불필요한 장면을 추가해 수량을 맞추지는 않는다.
- 최종 폰트가 로딩된 실제 화면으로 인접 장면 6개 내외를 함께 보고 크기·위치·정보 구조가 달라졌는지 확인한다. 메타데이터의 종류 개수만으로 통과시키지 않는다.
- 대표 배치별 등장·강조·홀드·전환 프레임과 최종 MP4 재생을 확인한다. 글자 넘침, 종이 경계의 글자 가림, 제목 침범, 선 정렬, 포인터 안전영역을 함께 검사한다.
- 검수용 HTML에는 실제 캔버스 크기를 설정한다. 빈 스크린샷이나 요소가 보이지 않는 화면은 오류 0건이어도 실패다.

수정 요청에서는 확정된 팔레트·음성·구간·CTA·썸네일 규격을 유지하고, 사용자가 요청한 배치와 모션을 개선한다. 영상 수정 요청이 실제 MP4 납품을 뜻하면 소스 수정만으로 완료 보고하지 않는다.
