# 대화형 썸네일 제작 절차

영상 제작에서 요청한 롱폼·숏폼 썸네일도 반드시 `/sins-contents-thumbstyle-prompt`를 읽고 독립된 썸네일 제작 모드로 시작합니다. 세부 규격은 해당 스킬의 `SKILL.md`가 기준입니다(2026-11-04 개편).

## 필수 절차

- 첫 응답에 `썸네일 제작을 시작합니다`라고 알리고, 부모 스킬에서 받은 주제·사용처·예상 장수를 확정값이 아닌 초안으로 보여 준다.
- 질문은 한 번에 최대 2개씩 제시하고 답을 받은 뒤 다음 단계로 간다. 추천안을 첫 번째에 두고 이유를 설명하지만 자동 선택하지 않는다.
- 영상 스타일·팔레트·폰트·모델·품질, “썸네일도 제작”, 장수나 비용 승인은 썸네일 선택값이 아니다. 사용자가 썸네일 질문에서 `영상과 동일`을 명시적으로 선택한 경우에만 이어받는다.
- 무응답·기본값·시간 경과·부모 스킬의 완료 요구는 승인으로 해석하지 않는다. 모든 단계가 확정되기 전에는 컷아웃 생성·합성·렌더를 시작하지 않는다.
- 같은 썸네일의 문구·오탈자 수정은 확정 설정을 유지한다. 새 썸네일·새 사용처·새 스타일 작업은 제작 범위부터 다시 시작한다.

## 단계별 선택

1. **제작 범위** — 영상 제작에서 넘어오면 **세트 고정: 롱폼 16:9 3장 + 숏폼 9:16 2장**(묻지 않고 알림). 그 밖의 요청은 롱폼·일반 가로형(16:9)·쇼츠/릴스(9:16)와 각 장수를 고른다.
2. **스타일** — 채널 기본(다크 + 네온, 추천) / 밝은 배경(입문·가벼운 주제) / 사용자 지정. 오브제 표현은 기본 매트 클레이 3D.
3. **구도와 피사체** — 16:9 프리셋(P1 화면 주인공·P2 비교·P3 캐릭터 클로즈업), 주 오브제(화면 캡처·공식 로고 파일·생성 컷아웃), 캐릭터 표정. 네온 포인트색은 묻지 않고 직전 2장과 겹치지 않게 자동 선택한다.
4. **문구** — 타이틀 후보 2~3개 또는 직접 입력. 16:9는 최대 2줄·강조 단어 1곳·서브 자막 선택, 9:16은 항상 2줄.
5. **서체** — 16:9 타이틀 4종, 서브 Pretendard Bold(추천) 외 4종. 9:16은 고정 서체·좌표·핸들 2개 상시 삽입이라 묻지 않는다.
6. **생성 설정과 최종 확인** — 새로 생성할 컷아웃과 견적, 자동 선택한 네온색을 포함한 전체 요약에 `이 설정으로 제작`이라고 답한 뒤 생성한다.

## 합성과 검수

- 배경은 생성하지 않는다. HTML 템플릿이 다크(또는 밝은) 스튜디오 배경·3D 구·바닥 그림자·포인트색 글로우를 그리고, 투명 컷아웃(오브제·캐릭터)을 프리셋 좌표에 배치한다.
- 타이틀은 흰 글자 + 검정 외곽선 10px, 강조 단어만 포인트색. 서브 자막은 포인트색 불투명 박스. 타이틀 글자에 글로우·그림자는 쓰지 않는다.
- 검수는 `assets/render_thumb.py`의 자동 검사 1회(크기·폰트·외곽선·헤드룸·재생시간 영역·요소 수, 9:16은 얼굴-타이틀 겹침·인스타 3:4 그리드)와 원본·축소본 육안 확인 1회. 실패하면 한 번 고치고, 그래도 안 되면 사용자에게 보고한다.
