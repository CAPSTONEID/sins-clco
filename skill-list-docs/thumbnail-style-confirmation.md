# 썸네일 필수 스타일 선택

영상 제작에서 요청한 롱폼·숏폼 썸네일도 반드시 `/sins-contents-thumbstyle-prompt`를 읽고 제작합니다. 해당 스킬과 `sins-video-consource` 패키지에 같은 스타일 확인 절차를 반영했습니다.

## 필수 절차

- 새 썸네일 작업은 롱폼·숏폼·일반 가로형 모두 **스타일 질문 → 사용자 답변 → 제작** 순서를 따른다. 영상 제작 스킬에서 넘어와도 이 단계를 생략하지 않는다.
- 해당 사용처에 맞는 스타일 후보 2~3개를 추천 이유와 함께 제시하고, 추천안을 먼저 둔다. 롱폼은 내용에 맞는 실사·3D·두들·페이퍼 콜라주 등을 검토하고, 숏폼은 `references/legacy-thumbnail-formats.md`의 스타일을 따른다. 혼합 패키지는 적용 대상을 밝혀 하나로 묻거나 롱폼·숏폼을 나눠 묻는다.
- 질문 예: “이번 썸네일은 어떤 스타일로 만들까요? 선택한 스타일을 롱폼 3장과 숏폼 2장에 적용하겠습니다.” 장수와 대상은 실제 요청으로 바꾼다.
- **사용자 답변 전에는 스타일을 확정하거나 배경 생성·합성·렌더를 시작하지 않는다.** 내용 분석과 후보 제안은 진행할 수 있다. 질문 도구가 없으면 채팅으로 묻고 답을 기다린다. 무응답·기본 선택·시간 경과를 승인으로 해석하지 않는다.
- 영상 스타일·팔레트 선택, 모델·품질·비용 승인, “썸네일도 제작”, “추천 설정으로 진행”을 썸네일 스타일 선택으로 간주하지 않는다. 자동 추천 요청이면 추천 스타일을 보여 주고 명시적 답변을 받는다.
- 사용자가 처음부터 특정 스타일을 지정했으면 그 스타일을 추천안으로 담아 적용 범위를 확인한다. 단, **이번 썸네일 작업의 스타일 질문에 이미 답했다면** 같은 질문을 반복하지 않고 그 답을 유지한다. 이후 문구·오탈자 수정만 할 때는 확정한 스타일을 이어받는다. 새 스타일로 바꾸는 경우 다시 묻는다.
- 기존 기획표 또는 프롬프트 TXT에 `thumbnail_style_question`, `thumbnail_style_answer`, `thumbnail_style_scope`를 기록한다. 사용자 답변이 없으면 `thumbnail_style_status: awaiting_user`이며 제작 완료로 처리하지 않는다. 답변과 범위가 있으면 `confirmed`로 기록한다.
